# HomeMap – Apple Maps-inspired interface refresh

Upload `index.html`, `manifest.webmanifest`, `sw.js`, and `icon.svg` into the root of your GitHub Pages repository and commit. Save a copy of your current index.html first.

This version has a cleaner, muted map base layer, floating search and map controls, a persistent rounded bottom home card, quick access to Places and Backup, and the interactive property editor. Street map tiles use CARTO/OSM; satellite imagery uses Esri. The UI is inspired by Apple Maps, not an exact copy of Apple's proprietary app or map imagery.

Pins and notes are saved locally in the browser. Export backups regularly; they do not automatically sync across devices.
